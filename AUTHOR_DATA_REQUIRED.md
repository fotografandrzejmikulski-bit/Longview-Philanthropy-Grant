# Author Data — Final Completion Sheet

Everything in the research and application package is intentionally written so that it does not require invented applicant credentials. The following fields are the only applicant-specific items that must be supplied before submission.

## Identity

- [ ] Full legal / application name
- [ ] Preferred professional name
- [ ] Email
- [ ] Country of residence
- [ ] City / region, if required by the application
- [ ] Website / portfolio / professional profile

## Education

- [ ] Highest completed degree
- [ ] Institution
- [ ] Field / discipline
- [ ] Graduation year
- [ ] Relevant additional training

## Research record

- [ ] Publications, preprints, reports, or substantial research outputs
- [ ] Links / DOIs where available
- [ ] Open-source repositories demonstrating relevant technical work
- [ ] Previous research projects and dates
- [ ] Relevant independent work / collaborations

## AI / technical evidence

For every competency claim made in the application, attach evidence where available:

- [ ] Mechanistic interpretability experience
- [ ] Sparse autoencoder / representation-analysis experience
- [ ] Evaluation / red-teaming experience
- [ ] Python / ML engineering evidence
- [ ] Relevant model, benchmark, or tooling work
- [ ] Experimental research experience

## Professional status

- [ ] Current employment / independent-research status
- [ ] Current institutional affiliation, if any
- [ ] Conflicts of interest
- [ ] Funding received for related work
- [ ] Relevant grants or fellowships

## References

- [ ] Referee 1: name, role, institution, contact
- [ ] Referee 2: name, role, institution, contact
- [ ] Optional third referee

## Application logistics

- [ ] Legal entity / fiscal sponsor information, if required
- [ ] Banking / payment information, if requested by the funder
- [ ] Eligibility confirmations for the specific future call
- [ ] Final requested amount
- [ ] Final project dates

## Submission integrity rule

Do not convert any unchecked item into a factual claim. Until evidence is supplied, use neutral wording such as "independent researcher" only when accurate, and do not state degrees, publications, affiliations, prior funding, technical achievements, endorsements, or institutional relationships that cannot be documented.

## Final gate

The package is considered author-complete when every applicable checkbox above is supported by a source document or a directly verifiable applicant statement. At that point, replace placeholders across the application documents and perform one final consistency review of names, dates, amounts, titles, links, and affiliations.
