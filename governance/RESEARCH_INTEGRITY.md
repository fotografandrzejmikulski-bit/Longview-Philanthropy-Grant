# Research Integrity Policy

## Non-negotiable standards

1. No hypothetical experiment is described as completed.
2. No credential, publication, employment, affiliation, or reference is stated without documentary support.
3. No result is reported without a defined evaluation procedure.
4. Exploratory analyses are labelled exploratory; confirmatory analyses use held-out data and preregistered hypotheses where practical.
5. Negative and null results are retained and reported.
6. Claims about consciousness, sentience, welfare, or moral status are explicitly separated from ordinary model-behavior observations.
7. The project records model versions, hashes, seeds, and experiment configuration sufficiently to reproduce results where safe.

## Claim taxonomy

### Established
Supported by directly verified evidence or reproducible project records.

### Supported inference
A conclusion strongly suggested by evidence but not directly demonstrated.

### Hypothesis
A proposition the project is testing.

### Speculation
A logically possible interpretation without adequate evidence.

Only the first two categories should be used for strong factual language in executive materials.

## Correction procedure

If an error is discovered in a public document, the repository should preserve the original version in Git history, correct the current document, and record the substantive change in the commit message or a change log. Material factual corrections should not be hidden by rewriting history.
