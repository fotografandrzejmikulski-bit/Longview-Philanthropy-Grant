# Indicative 18-month project budget

## Rationale

Longview's 2026 Extreme Power Concentration RFP described typical project grants of $100K–$2M/year for 6–18 months. The budget below is therefore a project-grant model rather than the previous fellowship-style two-year budget.

| Category | 18-month amount (USD) | Purpose |
|---|---:|---|
| Principal investigator / research lead | 180,000 | Research direction, experiment design, analysis, writing |
| ML research engineering | 135,000 | Experiment infrastructure, evaluation harness, reproducibility |
| Compute | 110,000 | Open-weight model experiments and mechanistic analysis |
| External red-team / independent replication | 45,000 | Adversarial evaluation and replication |
| Research operations / security | 25,000 | Artifact storage, access controls, logging, security review |
| Travel / conferences / workshops | 20,000 | Dissemination and expert engagement |
| Publication / data / tooling | 15,000 | Open-access, benchmark and documentation costs |
| Contingency | 20,000 | Unanticipated but mission-relevant expenses |
| **Total** | **550,000** | |

## No-funding fallback

Without funding, the project would be reduced to a smaller open-model study using publicly available compute, fewer variants, fewer independent replications, and a narrower integrity prototype. The highest-value activities retained would be threat-model formalization, baseline behavioral evaluation, provenance controls, and publication of negative or positive results.

## Budget principles

- Avoid presenting a salary as a “stipend” when the application is structured as a project grant.
- Avoid claiming that the maximum allowable amount is automatically justified.
- Tie compute spending to measurable experimental requirements.
- Preserve independent evaluation capacity as a distinct budget line.
